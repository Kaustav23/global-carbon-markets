# Global Carbon Compliance Architecture (2026–2035)

This repository contains a quantitative econometric engine and an interactive Streamlit dashboard modeling the transition of international compliance carbon markets. It focuses on benchmarking India's CCTS against major global regimes like the EU-ETS, UK-ETS, and China National ETS.

### How to Access the Dashboard and Use the Engine

To run the analytical engine and interact with the terminal locally, open your command prompt or terminal and run these exact commands:

```bash
# 1. Clone the repository to your machine
git clone [https://github.com/Kaustav23/global-carbon-markets.git](https://github.com/Kaustav23/global-carbon-markets.git)
cd global-carbon-markets

# 2. Install the required Python packages
pip install -r requirements.txt

# 3. Launch the interactive dashboard
streamlit run app/streamlit_dashboard.py
